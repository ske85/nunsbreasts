# nunsbreasts.com

Versione internazionale di [tettedellemonache.co](https://tettedellemonache.co/): inglese, francese, spagnolo, portoghese, cinese e giapponese.

Le pagine sono generate dal repository `tettedellemonache` (cartella `_i18n`): non modificarle a mano qui, ma aggiorna i testi là ed esegui `python3 _i18n/build.py ../nunsbreasts`.
